## 报价表与商业定价依据

报价表第一行放官方渠道，后续行列本次相关供应商渠道；各渠道使用同一可比较的计费项目与单位。
输入、缓存输入、输出、图片/视频不同规格或按次/按 token 不能混成一个无说明的单价，必要时分表。

| 渠道/供应商（官方首行） | 模型与计费项目 | 官方基准/渠道报价及币种单位 | 商务确认折扣与有效条件 | 实际采购成本 | 已确认对客售价/积分 | 价格文档与确认来源 | API 文档 |
|---|---|---|---|---|---|---|---|

展示来源与实际采用规则分开：官方标价不是自动采用的采购成本，渠道折扣也不自动决定对客售价。
采购价格先取得商务确认来源，开发再复核模型、账户、折扣及计费规则；已有明确证据不重复请求确认。
提供来源链接、版本/读取日期和适用范围，截图、未读嵌入表格或冲突报价保留待核对，不能编造精确值。
只使用用户提供或明确允许读取的飞书文档，不因样例内出现价格链接就自动扩大到其他飞书文档。
未知价格明确待定，继续独立开发；不以旧价或示例价替代，不把未知值填成 0。
附预估费用入口、计费维度、单位、取整、渠道/免费差异，价格落库与公式检查见 [数据库与计费](database-pricing.md)。

## 项目连接点

基线：2026-11-12 `main@171e86591` 源码核查；执行时按当前文件复核并记录相关未提交改动。

- `internal/logic/model/listlogic.go::List`：遍历 YAML Models，按 ModelID 查 DB，将本地化后的 config_detail 返回为 ExtInfo；处理 page、canvas_show 和展示名覆盖。
- `internal/logic/common/llm_model.go::GetModelExtInfoWithDB`：该列表路径实时查库，不凭存在缓存函数机械安排清缓存。
- `internal/pkg/i18n/config_detail.go::ApplyLocaleOverride`：语言根浅覆盖后删除语言节点，不为缺字段的 field_map 深度补齐。
- `internal/types/video.go::GetPrompt`：素材引用转换受具体调用路径、模型和 `AtConfig` 影响，不是所有请求的全局前置步骤。
- 请求类型：`internal/types/chat.go`、`image.go`、`video.go`；完整路由以 `internal/handler/routes.go` 为准，不猜前缀。

画布入口须检查本地化后的 `canvas_show` 为 JSON 布尔值 `true`；请求 `canvas_show=true` 时，缺字段、false、字符串或数字都不能通过当前筛选。
分别用 `zh-CN`、`en-US` 核对展示名、参数 schema 和画布可见性；当前 locale 使用 `Accept-Language`，支持集合和缺省按 `internal/pkg/i18n/locale.go` 复核。
语言节点是浅层覆盖，不能假设另一语言会补齐缺失 `field_map`；保留既有未知字段和语言，不将新文案覆盖为不完整 JSON。
